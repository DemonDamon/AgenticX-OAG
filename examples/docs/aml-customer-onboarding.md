# 客户开户与尽调记录

2026 年 3 月，华东分行完成四名新客户的开户与风险等级评定。

对公客户华信国际贸易有限公司（客户编号 C-001）主营进出口贸易，成立于 2012 年，注册地为华东地区，因涉及高风险国别收付款被评定为高风险（high）等级，开立对公账户 A-101。个人客户张伟（C-002）评定为中风险（medium），开立个人账户 A-102；李娜（C-003）为低风险（low），开立个人账户 A-103；王强（C-004）为中风险（medium），暂未开户。

合规部对华信国际贸易启动增强型尽职调查，形成尽调报告 D-501，结论为「持续监控」；对张伟完成标准尽调，报告编号 D-502，结论为「无异常」。
